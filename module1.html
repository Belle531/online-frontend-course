Module 1: Computer Basics

Welcome to the very beginning of your journey! Before we start building websites, it's important to understand the fundamental components of a computer and how they work together.

What You'll Learn

  • Understand the difference between computer hardware and software.
  • Recognize the role of an operating system.
  • Learn basic file and folder organization.
  • Understand the concept of a file path.

1. Hardware vs. Software

At its core, a computer is made of two parts: **hardware** and **software**. Hardware is any physical component you can touch, like the keyboard, mouse, or the internal hard drive. Software is the collection of programs, data, and instructions that tell the hardware what to do. Think of your web browser, a game, or a text editor—these are all examples of software.

2. Operating Systems

An **Operating System** (OS) is the most important software on a computer. It manages the hardware and software resources, provides a user interface, and allows other programs to run. Common examples include Windows, macOS, and Linux. The OS is the bridge between you and the computer's physical components.

3. Files, Folders, and Paths

Files and folders are how we organize information on a computer. A **file** is a digital document, like a text file or an image. A **folder** (or directory) is a container for organizing files and other folders.

Every file and folder has a **file path**, which is like its address on the computer. For example, a file path might look like `C:\Users\YourName\Documents\project\index.html`. Understanding these paths is crucial for developers.
